Address Book Application in C

📌 Description

The Address Book is a console-based application developed using C programming to manage contact information efficiently. It allows users to add, search, edit, delete, and display contacts, including names, phone numbers, and email addresses. File handling is used to store and retrieve contact information.

✨ Features

- Add new contacts.
- Search for existing contacts.
- Edit contact information.
- Delete contacts.
- Display all saved contacts.
- Save and retrieve contact details using file handling.

 Technologies Used

- Language: C
- Concepts: Structures, Pointers, Functions, File Handling, String Manipulation, and Modular Programming.
- Compiler: GCC
  
 Learning Outcomes

- Gained practical experience in C programming.
- Improved understanding of structures, pointers, and functions.
- Learned to perform file operations for data persistence.
- Applied modular programming to develop a menu-driven application.
